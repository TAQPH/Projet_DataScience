# AI Usage Declaration

AI tools were used to build this project as support tools.

ChatGPT was used to:
- clarify conceptual questions related to machine learning and data preprocessing,
- assist with code structuring and debugging,
- help reformulate and improve the clarity of certain parts of the written report and documentation.

DeepL was used to assist with English phrasing and translation.

All modeling decisions, data preprocessing choices, implementation, analysis, and interpretations were fully understood and validated by the author. No code or content was included without being reviewed, adapted, and verified.
